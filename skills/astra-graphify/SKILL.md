# ASTRA Graphify
Use official upstream https://github.com/Graphify-Labs/graphify and package graphifyy. Install in an isolated environment after reviewing and pinning a verified release. Register project skill with `graphify install --project --platform agents`; Gemini CLI: `graphify install --project --platform gemini`. Build with `/graphify .` only in a sanitized, explicitly approved workspace. Never scan credentials, private documents, BHXH data, or home directories. Keep graph outputs outside public repositories. Query the local graph first when current and available; verify important claims against original sources and commit IDs. Fall back to ordinary source navigation if graph is missing or stale. Do not claim MCP is connected without runtime evidence. Do not claim token savings without measurement. Record graph build date, source revision, version, errors and actual results.
